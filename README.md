# Who-Wants-To-Be-a-Millionaire-Game
🎮 A Python-based quiz game inspired by KBC, featuring multiple-choice questions, prize levels, and score tracking.
## Features
- Multiple-choice questions
- Prize money system
- Instant feedback for correct and incorrect answers
- Game ends when a wrong answer is selected
- Tracks winnings after each correct answer

## Technologies Used
- Python 3

## How to Play
1. Run the Python script.
2. Read the question and options carefully.
3. Enter:
   - 1 for option A
   - 2 for option B
   - 3 for option C
   - 4 for option D
4. Earn prize money for each correct answer.
5. The game ends when an incorrect answer is given.
